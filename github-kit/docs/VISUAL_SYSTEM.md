# VISUAL SYSTEM

## Palette

Obsidian / near-black · 24K gold · muted teal/cyan · ivory/snow white · titanium/platinum

## Image language

Cinematic documentary photography, deep controlled blacks, soft highlights, subtle gold reflections, teal technical light, geometric overlays, editorial serif for headlines, clean sans-serif for metadata.

## Asset classes

A. Profile banner — 1280×640 or wider source  
B. Repository social preview — 1280×640  
C. README hero — same visual family as the social preview  
D. Architecture — preferably SVG  
E. Screenshots — real product/interface screenshots

## Rules

Do not use fake metrics, invented screenshots, unrelated stock imagery or decorative graphics with no explanatory role.
