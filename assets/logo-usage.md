# Logo system — mojealterego

## Master reference
The supplied full-color logo is the visual master reference for the site identity:
- crown + laurel + AM monogram;
- ANDRZEJ MIKULSKI wordmark;
- decorative divider;
- handwritten Mojealterego signature beneath the wordmark.

## Usage hierarchy
1. Full master logo: hero, footer/brand pages, social/OG artwork.
2. Compact horizontal mark: desktop navigation.
3. Compact mobile mark: mobile navigation.
4. AM monogram: favicon/app icon and compact UI.
5. Signature lockup: editorial section accents.

## Material language
Primary surface: black aniline leather / matte black luxury material.
Metallic accent: restrained 24K-gold appearance.
Supporting accents: burgundy, royal blue, bottle green, titanium/platinum and copper.

The logo itself must not be recolored per section. Section colors belong to the surrounding visual system; the master logo remains the identity anchor.

## Typography
The handwritten `Mojealterego` treatment is part of the supplied visual reference. A web fallback may be used only until an exact vector/transparent asset is supplied.
